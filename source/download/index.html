Install

Install in a few easy steps.

Installing on Windows

Windows shows a blue warning the first time, because Thiran is a new app that isn't signed yet. That's expected. Here's how to get past it.

1Open the download

When the download finishes, click Open file in your browser's downloads. The file is called Thiran-Setup-0.17.12.exe.

Some browsers first say the file "isn't commonly downloaded". If yours does, choose Keep.

2"Windows protected your PC"

Windows may show a blue box that says Windows protected your PC. This is Microsoft Defender SmartScreen, and it appears for new apps that aren't signed yet. Click More info.

3Run anyway

You'll see App: Thiran-Setup-0.17.12.exe and Publisher: Unknown publisher. Click Run anyway.

4Install

Follow the Thiran Setup steps. You can install just for you, without administrator rights.

Setup may ask whether to add the Thiran PDF printer, which lets any program print straight into Thiran. This is optional, and adding it needs administrator permission.

When setup finishes, Thiran opens. You'll find it in the Start menu and on your desktop.

Installing on Mac

macOS asks you to allow Thiran once, because it's a new app that Apple hasn't checked (notarised) yet. It takes about a minute, and you only do it once on each Mac.

1Drag Thiran into Applications

Open Thiran-0.17.12-mac-universal.dmg. A window called Thiran 0.17.12 opens. Drag Thiran onto Applications.

2Open Thiran, then click Done

Open Thiran from your Applications folder. macOS says "Thiran" Not Opened and Apple could not verify "Thiran" is free of malware that may harm your Mac or compromise your privacy. This is normal for an app that isn't notarised yet. Click Done. Don't choose Move to Trash.

3Allow it in System Settings

Open System Settings › Privacy & Security. Scroll down to Security, find "Thiran" was blocked to protect your Mac., and click Open Anyway.

The button shows for about an hour after you try to open the app. If you don't see it, open Thiran again and come back.

4Confirm

macOS asks once more. Click Open Anyway, then confirm with your Mac password or Touch ID. Thiran opens, and from now on it opens normally.

Older macOS: on macOS 13 or 14 the wording is a little different ("can't be opened because Apple cannot check it for malicious software"), but the steps are the same: click OK, then open System Settings › Privacy & Security and click Open Anyway.

Updates

Windows

Thiran updates itself. It downloads new versions in the background and shows Restart to update. If you don't restart, the update installs the next time you close Thiran.

Mac

For now, you install a new version yourself. Download it from this page and drag it into Applications again, replacing the old one. Your account and work aren't affected.

Is it safe?

Why the warning?

Thiran is a new app. Windows and macOS show these warnings for apps whose installers aren't yet signed (Windows) or notarised by Apple (Mac). The warning means the system couldn't check the app, not that it found anything wrong. We're working on signing.
